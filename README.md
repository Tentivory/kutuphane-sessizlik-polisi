# Kütüphane Sessizlik Polisi

Bu proje, insanlık tarihinin en ciddi kamu düzeni sorununu çözer: **kafanın içinde çok sesli düşünmek**.

Dışarıdan bakınca kimse konuşmuyor. İçeride ise bir orkestra prova yapıyor. Bu yazılım o orkestrayı ölçer, puanlar ve gerekirse **resmi düşünce tutanağı** keser.

## Neden var?

Çünkü sessizlik bir lüks değildir. Sessizlik bir kamu hizmetidir. Kamu hizmeti de ancak abartılı bir protokolle korunur.

Bu depo:
- Gerçekten çalışır.
- Hiçbir şeyi düzeltmez.
- Buna rağmen çok resmi durur.

## Kurulum

```bash
python3 polisi.py
```

İsteğe bağlı argüman:

```bash
python3 polisi.py --ruh-hali kaygili
python3 polisi.py --ruh-hali gururlu
python3 polisi.py --ruh-hali uykulu
```

## Çıktı örneği

Program şunları üretir:
- Düşünce desibeli
- İhlal sınıfı
- Ceza önerisi (hep sembolik)
- Resmi tutanak numarası
